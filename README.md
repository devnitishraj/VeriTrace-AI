# VeriTrace AI

## AI-Powered Digital Media Forensics & Verification

VeriTrace AI is a digital media forensic analysis and verification system designed to analyze uploaded media and provide a forensic risk assessment.

## Features

- 🎥 Video upload and analysis
- 🔍 Digital media forensic analysis
- 🛡️ Verification risk assessment
- 📊 Risk score and verification status
- ⚡ User-friendly web interface
- 🔗 Frontend and backend architecture
